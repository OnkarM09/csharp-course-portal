Section 26: String Manipulation, DateTime & Math

Detailed architectural breakdown integrating comprehensive explanations, syntax reference matrices, compiler internals, and production C# code.

1. String Immutability & The String Intern Pool

In C#, string is an alias for System.String. While it feels like a primitive, it is a reference type allocated on the managed heap. The defining characteristic of C# strings is that they are immutable—once created in memory, a string instance can never be modified:

🔵 Core Concept (from Notes)

When you write: 

string s = "Hello";
s = s + " World";

The original "Hello" object on the heap is NOT modified! The CLR allocates an entirely new string object of length 11 on the heap, copies both pieces of text into it, and updates the reference variable s. The original "Hello" becomes orphaned GC garbage.

🟣 Under the Hood / Compiler Lowering

To conserve heap memory, the CLR maintains a private internal table called the String Intern Pool. At startup, the runtime scans your assembly's metadata for literal string constants. If two separate classes declare "SUCCESS", the CLR allocates only one instance in the intern pool and points both references to the exact same heap memory address!

2. StringBuilder vs String Concatenation Performance

Concatenating strings inside a loop using += creates an O(n²) memory explosion. Use System.Text.StringBuilder for multi-step string generation:

StringBuilder vs Concatenation 
using System.Text;

// ANTI-PATTERN: Generates 1,000 intermediate heap garbage objects!
string badResult = "";
for (int i = 0; i < 1000; i++)
{
    badResult += i + ", ";
}

// PRODUCTION PATTERN: Zero garbage, pre-allocated internal buffer
var sb = new StringBuilder(4000); // Pre-size capacity!
for (int i = 0; i < 1000; i++)
{
    sb.Append(i).Append(", ");
}
string cleanResult = sb.ToString();

Comparing strings using == performs ordinal comparison, but may fail subtle security or localization requirements:

System.Math Methods

Console.WriteLine(Math.Round(4.5, MidpointRounding.AwayFromZero)); // 5
Console.WriteLine(Math.Clamp(120, 0, 100));     // Clamps to 100! (.NET Core+)

6. String & Time Traps

🟠 Compiler Trap & Common Gotcha

Bug: Recording database timestamps with DateTime.Now.

Consequence: If server A is in New York (EST) and server B is in London (GMT), orders processed at the exact same physical second will have timestamps 5 hours apart!

Rule: Always persist DateTimeOffset.UtcNow in databases and APIs. Convert to the client's local timezone only at the presentation layer.
