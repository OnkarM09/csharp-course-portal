Section 35: C# 12 New Features (.NET 8)

Detailed architectural breakdown integrating comprehensive explanations, syntax reference matrices, compiler internals, and production C# code.

1. Primary Constructors for Classes & Structs

C# 12 expands primary constructors beyond records to ordinary class and struct declarations. Constructor parameters are declared directly in the class header and are in scope throughout the entire class body:

Primary Constructor in C# 12 
// Modern C# 12 Class with Primary Constructor (Ideal for Dependency Injection!)
public class OrderService(
    IOrderRepository repository, 
    ILogger logger, 
    IEmailSender emailSender)
{
    public async Task ProcessOrderAsync(int orderId)
    {
        logger.Log($"Processing order {orderId}...");
        var order = await repository.GetByIdAsync(orderId);
        await emailSender.SendConfirmationAsync(order);
    }
}

2. Unified Collection Expressions ([...])

Prior to C# 12, instantiating different collection types required different syntax. C# 12 unifies everything under clean bracket syntax [...]:

Unified Collection Expressions 
// Universal collection expressions:
int[] array = [1, 2, 3, 4];
List<string> list = ["Alice", "Bob", "Charlie"];
Span<byte> span = [0x01, 0x02, 0x03];
ImmutableArray<int> immutable = [10, 20, 30];

3. The Spread Operator (..collection)

The spread operator (..) inlines elements of one collection into another without loops or calls to Concat():

Spread Operator 
int[] initial = [1, 2, 3];
int[] secondary = [4, 5, 6];

// Spread operator combines collections inlined!
int[] combined = [..initial, 999, ..secondary]; // [1, 2, 3, 999, 4, 5, 6]

4. Inline Arrays for High-Performance Buffers

[InlineArray(N)] enables structs with fixed contiguous buffers without requiring unsafe pointers:

Inline Array 
[System.Runtime.CompilerServices.InlineArray(10)]
public struct Buffer10<T>
{
    private T _firstElement;
}

// Caller can index up to 10 elements safely on the stack!
var buffer = new Buffer10<int>();
buffer[0] = 42;
buffer[9] = 99;

5. Default Lambda Parameters & Alias Any Type

Default Lambdas and Type Aliasing 
// 1. Lambda with default parameter value
var greet = (string name = "Guest") => $"Hello, {name}!";
Console.WriteLine(greet());         // Hello, Guest!
Console.WriteLine(greet("Alice"));  // Hello, Alice!

// 2. Alias ANY type (tuples, arrays, pointers)
using MeasurementPoint = (double Latitude, double Longitude, double Elevation);

6. C# 12 Primary Constructor Traps

🟠 Compiler Trap & Common Gotcha

Trap: In records, record Person(string Name) creates a public property. In ordinary classes, class Person(string name) does NOT create a property!

The parameter name is merely captured by members that reference it. If no member references it, it is not stored in the object payload at all!
