Section 13: Partial Classes, Static Classes & Enums

Detailed architectural breakdown integrating comprehensive explanations, syntax reference matrices, compiler internals, and production C# code.

1. Partial Classes & Source Generation

The partial keyword allows the declaration of a single class, struct, or interface to be split across multiple physical .cs files. At compile time, the Roslyn compiler merges all partial segments into a single unified type:

🔵 Core Concept (from Notes)

Partial classes were introduced to solve the problem of visual designer tool code generation (e.g., WPF XAML, WinForms designer, Entity Framework EDMX, and modern Roslyn Source Generators). Machine-generated code lives safely in one file (e.g. UserForm.Designer.cs), while your human domain code lives in another (UserForm.cs), preventing automated tooling from wiping out your custom code!

2. Partial Methods & Compiler Stripping

A partial class can declare a partial method signature in one file and optionally implement it in another. If the implementation is omitted, the compiler completely eliminates the declaration and all calling code with zero runtime footprint!

3. Static Classes & Stateless Utility Toolboxes

A class marked static acts as a pure utility toolbox (like System.Math). Strict compiler rules apply:

  • Cannot be instantiated using new (compiler error CS0712).
  • Cannot be inherited or inherit from anything other than System.Object.
  • Must contain only static members (fields, properties, methods).
  • Cannot contain instance constructors.

4. Enumerations: Type-Safe Integral Constants

An enum defines a strongly typed set of named integral constants:

Explicit Underlying Type Enum 
public enum OrderStatus : byte
{
    Pending = 1,
    Processing = 2,
    Shipped = 3,
    Delivered = 4,
    Cancelled = 99
}

OrderStatus status = OrderStatus.Processing;
Console.WriteLine($"Status: {status} (Numeric: {(byte)status})");

5. Bitwise Flag Enumerations ([Flags])

When an enum represents combinations of options, decorate it with [Flags] and assign values as powers of 2 (1, 2, 4, 8, 16...):

Bitwise Flags Enum 
[Flags]
public enum FilePermissions
{
    None = 0,
    Read = 1 << 0,       // 1
    Write = 1 << 1,      // 2
    Execute = 1 << 2,    // 4
    All = Read | Write | Execute // 7
}

// Combining permissions with bitwise OR (|)
var userPerms = FilePermissions.Read | FilePermissions.Write;

// Checking permissions with HasFlag or bitwise AND (&)
bool canWrite = userPerms.HasFlag(FilePermissions.Write);
Console.WriteLine($"Can write: {canWrite}"); // True

6. Enum & Static Class Gotchas

🟠 Compiler Trap & Common Gotcha

Trap: Assuming an enum variable always contains one of its declared members! 

OrderStatus status = (OrderStatus)888; // Compiles and runs without error!

Fix: In defensive code, use Enum.IsDefined(typeof(OrderStatus), status) before processing unknown values.
