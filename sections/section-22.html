Section 22: Collections (Lists, Dictionaries, Sets, Queues)

Detailed architectural breakdown integrating comprehensive explanations, syntax reference matrices, compiler internals, and production C# code.

1. The Collections Architecture & Interfaces

While arrays are fixed-size, collections are dynamically growing data structures designed to store, organize, and manipulate arbitrary quantities of items. All generic collections in System.Collections.Generic participate in a unified interface hierarchy:

  • IEnumerable<T>: Base interface allowing forward iteration via foreach.
  • ICollection<T>: Extends iteration with Count, Add(), Remove(), and Contains().
  • IList<T>: Adds indexed access (this[int index]) and insertion at specific indices.
  • IDictionary<TKey, TValue>: Key-value mapped collection with fast hashed retrieval.

2. List<T> Internal Array Doubling & Amortized O(1)

List<T> is backed internally by a contiguous array. When the array fills, List<T> allocates a new array of double the size and copies existing elements over:

📊 Diagram: List<T> Array Doubling Expansion
Initial:   [Capacity: 4, Count: 4] -> [A | B | C | D]
Add item:  Capacity is full!
Step 1:    Allocate new array on Heap of Capacity = 8
Step 2:    Copy [A, B, C, D] to new buffer
Step 3:    Insert [E] -> [A | B | C | D | E | _ | _ | _]
Step 4:    Old array of size 4 becomes GC garbage!
🟢 Best Practice & Architecture Tip

If you know you are inserting 100,000 items, instantiate var list = new List<Customer>(100_000);. This eliminates 17 redundant array allocations and saves massive CPU copying and GC overhead!

3. Dictionary<TKey, TValue> & Hash Table Buckets

Dictionary<TKey, TValue> provides near-instantaneous O(1) lookups, insertions, and deletions using hash table buckets:

  1. Computes key.GetHashCode().
  2. Calculates bucket index: abs(hashCode) % bucketCount.
  3. Navigates to the bucket entry array to match exact key using key.Equals(entry.Key).
Dictionary Operations 
var userCache = new Dictionary<int, string>()
{
    { 101, "Alice" },
    { 102, "Bob" }
};

// Safe lookup with TryGetValue (never throws KeyNotFoundException)
if (userCache.TryGetValue(101, out string? username))
{
    Console.WriteLine($"Found user: {username}");
}

4. HashSet<T> & High-Speed Set Theory Math

A HashSet<T> stores unique elements with zero duplicates and provides high-speed mathematical set operations:

HashSet Math Operations 
var engineers = new HashSet<string> { "Alice", "Bob", "Charlie" };
var managers = new HashSet<string> { "Charlie", "Dave" };

// Set Intersection: who is BOTH an engineer and manager?
var dualRoles = new HashSet<string>(engineers);
dualRoles.IntersectWith(managers); // Contains only "Charlie"

5. Queue<T> (FIFO) vs Stack<T> (LIFO)

Queue<T> operates on First-In-First-Out (FIFO) mechanics using Enqueue() and Dequeue(). Stack<T> operates on Last-In-First-Out (LIFO) mechanics using Push() and Pop().

7. Collection Traps & Modification Exceptions

🟠 Compiler Trap & Common Gotcha

Error: Calling list.Add() or list.Remove() inside a foreach loop: 

foreach (var item in list)
{
    if (item.IsExpired) list.Remove(item); // System.InvalidOperationException: Collection was modified!
}

Fix: Use list.RemoveAll(x => x.IsExpired); or iterate backward using a traditional for loop.
